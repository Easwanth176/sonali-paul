# Sonali Paul — Portfolio

Personal portfolio site (Next.js + TypeScript + Tailwind), inspired by a modern single-page layout with Sonali’s CV data.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Content

Edit `src/lib/site-data.ts` to update copy, projects, and stats.

## Deploy

Push to GitHub and import the repo on [Vercel](https://vercel.com) (framework preset: Next.js).

Assets: `public/sonali-paul.jpeg`, `public/CV-sonali-paul.pdf`.
